## Scope
Booking Management covers two related flows:
1. **Cart Management** (Angular Practice Shop) — add products, view cart, checkout
2. **Order Placement & History** (Client App) — add to cart, place order, view orders

## Happy Path Scenarios (TC-001 to TC-099)

### TC-001: Add single product to cart and verify cart count
**Category**: Happy Path
**Priority**: P0
**Preconditions**: User logged in via `/loginpagePractise/` (User role)
**Steps**:
1. Login with valid credentials (username + password + terms checkbox)
2. Land on `/angularpractice/shop`
3. Locate product card "iphone X"
4. Click "Add" button on iphone X card
**Expected Results**:
- Checkout nav link updates to `Checkout (1)`
- No error displayed
**Business Rule**: Each "Add" click adds 1 unit to cart
**Suggested Layer**: E2E
