## Decision rationale

Both scenarios are multi-step, full-stack journeys (form fill → real
authentication call → redirect/toast) — rule 4 ("multi-page journey or
full-stack flow → E2E") applies directly. Neither is pure input validation or
an isolated function, so there's no lower layer to push either down to.
